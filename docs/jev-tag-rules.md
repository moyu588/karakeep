# Jev Tag 归并判断规则

- 状态：已按 2026-09-29 人工确认边界定稿
- 数据来源：Karakeep REST API `/api/v1/tags`
- 拉取时间：2026-09-29 13:14 CST
- Tag 总数：190
- 目标：只合并语义重复或同一业务概念的 tag；保留项目名、产品名、厂商名和细粒度检索价值高的 tag。

## 核心判断原则

1. **候选 tag 与 canonical tag 表示同一概念时才映射。**
   - 允许：同义词、大小写/分隔符差异、中文/英文常见翻译、简称/全称。
   - 不允许：只是相关、父子关系、工具与用途关系、供应商与领域关系。
2. **优先保留信息量更高的具体 tag。**
   - `Claude Code`、`Codex`、`MCP`、`Obsidian`、`yt-dlp` 等专有名词不并入大领域。
3. **候选名称本身含义不足时返回 `NONE`。**
   - 例如 `安全` 不能仅凭名称判断应归入 `Web安全`、`网络安全`、`安全工具` 还是其他领域。
4. **一个概念只保留一个 canonical tag。**
   - 如果多个候选都指向同一概念，统一映射到清单中已有、使用量更高或表达更标准的名称。
5. **宁可进入人工确认，也不要错误自动合并。**
   - 高置信度才自动 alias；
   - 中置信度生成待确认建议；
   - 低置信度或含义不明保持 `NONE`。

## 明确归并组

### IP / 代理质量检测

Canonical tag：

- `IP检测`

可归并：

| 候选 tag | 判断 |
|---|---|
| `IP风险` | 同一 IP 质量检测概念 |
| `IP查询` | 同一 IP 信息查询/检测概念 |
| `IP地理定位` | IP 检测能力的一部分 |
| `IP纯净度` | IP 质量/干净度判断 |
| `CleanIP` | IP 纯净度/干净度判断 |
| `代理检测` | IP 代理属性检测 |
| `ASN` | IP 信息/风险检测中的常见属性 |

暂不归并：

- `SOCKS5`：代理协议/基础设施，不只是检测。
- `DNS泄漏`：隐私/安全诊断主题，保留独立检索价值。
- `DDoS防护`：防护能力，不是 IP 检测。
- `流量转发`：网络转发/代理基础设施，不是检测。

### 搜索

经查证书签：

- `互联网搜索` 当前只对应 `Agent-Reach`，该项目是让 AI Agent 读取/搜索多个互联网平台的 CLI，核心是 Agent 数据接入，不只是通用 Web 搜索。
- `Web搜索` 当前只对应 `firecrawl`，该项目覆盖搜索、抓取、页面交互和网页数据 API。

结论：

- **`互联网搜索` 不合并到 `Web搜索`。**
- `Agent_Reach` 是具体项目 tag，保留。
- 未来新增 tag 时，只有明确表示通用 Web 搜索能力，才映射到 `Web搜索`；网站抓取/数据提取、多平台 Agent 接入都返回 `NONE`。

### 媒体下载

Canonical tag：

- `视频下载`

可归并：

| 候选 tag | 判断 |
|---|---|
| `媒体下载器` | 泛指媒体/视频下载能力 |

暂不归并：

- `yt-dlp`：具体工具名。
- `Invidious`：具体前端/服务项目。
- `YouTube`：平台名。
- `视频分析`、`视频生成`、`视频渲染`：不同能力。

## 领域边界规则

### Agent / 智能体

- `Agent`：通用 autonomous agent、agent framework、agent runtime。
- `多智能体`：明确描述多个 agent 协作/编排时保留。
- `智能体课堂`、`智能体配置`、`智能体优化`、`智能体工程`、`智能体源代码审查`：细粒度主题，保留。
- 具体项目如 `PentAGI`、`Hermes`、`Orca`、`Paseo`：保留。

### LLM / AI

- `LLM`：通用大语言模型主题。
- `LLM安全`：LLM 安全主题。
- `Prompt_Engineering`：提示词工程。
- `Prompt_Injection`：具体攻击/防御主题，不并入 `LLM安全`。
- `越狱提示词`：具体提示词攻击材料/技术，暂不并入 `Prompt_Injection`，除非你确认要合并。
- 模型/厂商保留：`OpenAI`、`Anthropic`、`DeepSeek`、`GLM`、`PaddlePaddle`。
- 具体产品/项目保留：`Claude Code`、`Codex`、`DeepTutor`、`HiveNova`、`Jev`。

### 安全

- `红队`、`渗透测试`、`漏洞研究`、`安全审计`、`Web安全`、`网络安全`、`安全运营`、`蓝队`、`应急响应`、`CTF`、`Bug_Bounty`：保持独立。
- `安全工具`：只表示工具集合/工具项目。
- `安全检测`：若明确表示通用安全检测能力，可进入人工确认；不要自动并入 `安全工具`。
- `CVE`、`POC`、`EXP`：漏洞研究相关对象/产物，保留细粒度。
- `MITRE_ATT&CK`、`知道创宇`、`长亭`、`渊龙Sec`、`404StarLink`、`HackerOne`：框架、厂商、平台或资源源，保留。
- `安全`：含义不足，默认返回 `NONE`。

### 开发 / 代码

- `AI编程`、`代码审查`、`代码分析`、`代码理解`、`自动化测试`：不同主题，保留。
- `智能体源代码审查`：agent 场景下的源码审查，不并入普通 `代码审查`。
- `Git`、`GitHub`、`开源`：分别是版本控制、平台和开源属性，不互相合并。
- `TypeScript`、`Rust`、`Python`、`Next.js`：语言/框架，保留。
- `开发效率`：效率主题，不并入通用开发标签。

### 浏览器 / 抓取

- `浏览器`、`Chrome`、`Chromium`、`Chrome扩展`：浏览器、内核、扩展不同层级，保留。
- `浏览器自动化`：自动化能力主题。
- `爬虫`：抓取主题。
- `Crawl4AI`、`firecrawl`：具体项目，保留。

### 文档 / OCR / PDF

- `OCR`：通用 OCR 能力。
- `PaddleOCR`：具体项目，保留。
- `PDF`：格式主题。
- `文档转换`、`Markdown`、`文档驱动`：不同文档处理主题，保留。
- `DESIGN.md`、`awesome_design_md`：疑似特定资源/文件集合，保留。

### UI / 设计

- `UI设计`、`UI生成`、`设计系统`、`HTML动画`、`图表美化`、`插画`：保留细粒度。
- 通用设计资料可保留 `DESIGN.md` 或 `awesome_design_md`，不要合并到 `UI设计`。

### 部署 / 自托管 / 运维

- `自托管`、`Docker`、`VPS`、`Linux`、`运维`、`远程访问`、`远程运行时`、`KasmVNC`：保留。
- `镜像`：如明确是 Docker/系统镜像主题，仍建议保留；不要自动并入 `Docker`。
- `安装部署`：部署主题，可保留；若后续书签证明只是 Docker 部署，可人工合并。

### 知识 / 学习 / 记忆

- `知识图谱`、`长期记忆`、`记忆系统`、`个性化学习`、`课程生成`、`智能体课堂`：保留。
- `Obsidian`：具体工具，保留。
- `每日简报`、`新闻聚合`：内容形态不同，保留。

## Jev 输出规则

候选 tag：`<candidate>`

候选 canonical tags：

```text
<已有 canonical tag 列表>
```

判断要求：

1. 只有候选名称与某个 canonical tag 表示同一概念时，才返回该 canonical tag。
2. 如果只是相关、父子关系、工具与用途关系，返回 `NONE`。
3. 如果候选名称不足以判断具体领域，返回 `NONE`。
4. `confidence` 表示对当前选择的确定度，不是语义相似度。
5. 对正确映射但 confidence 低于当前阈值的样本，应进入人工确认，而不是自动 alias。
